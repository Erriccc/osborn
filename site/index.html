How it works

You talk

Real-time voice over LiveKit WebRTC — interrupt it, think out loud, no typing.

It reasons

A persistent Claude Agent SDK session with researcher / reasoner / writer sub-agents.

It builds

Reads code, searches the web, runs commands, writes plans and diffs — in your workspace.

Build with us

It's open source (MIT). Grab an issue, open a PR, or just tell us what you'd want it to do.
