================================================================================
CLAUDE AGENT SDK - HOOKS & NOTIFICATIONS IMPLEMENTATION GUIDE
================================================================================

This document explains how to implement hooks for logging and user notifications
when using the Claude Agent SDK (@anthropic-ai/claude-agent-sdk).

================================================================================
CURRENT IMPLEMENTATION STATUS
================================================================================
 we want the voice llm/agent to be aware of whats going on withing the coding agent and give update, guide user through claudes process/reasoning and ask for permissions etc 
The current implementation in agent/src/claude-handler.ts ALREADY INCLUDES:

1. PreToolUse Hook (lines 66-94)
   - Logs tool name before execution
   - Emits 'tool_use' event with tool name and input
   - Handles permission requests for dangerous tools (Bash, Write, Edit)

2. PostToolUse Hook (lines 95-103)
   - Logs tool completion
   - Emits 'tool_result' event

3. Event Listeners in index.ts (line 139-141)
   - Listens for 'tool_use' events from ClaudeHandler
   - Currently only logs to console

WHAT'S MISSING:
   - Frontend notifications for real-time activity updates
   - Detailed tool-specific notifications
   - Session lifecycle hooks (SessionStart, SessionEnd)
   - Error/failure hooks (PostToolUseFailure)
   - Progress tracking for long-running tools
   - UserPromptSubmit hook for logging prompts

================================================================================
AVAILABLE HOOK EVENTS IN CLAUDE AGENT SDK
================================================================================

The SDK exposes these hook events (from agentSdkTypes.d.ts line 172):

| Hook Event          | When It Fires                              |
|---------------------|-------------------------------------------|
| PreToolUse          | Before any tool executes                  |
| PostToolUse         | After a tool completes successfully       |
| PostToolUseFailure  | After a tool fails or errors              |
| Notification        | System notifications from Claude          |
| UserPromptSubmit    | When user submits a prompt                |
| SessionStart        | Session starts (startup/resume/clear)     |
| SessionEnd          | Session ends                              |
| Stop                | Execution is stopped                      |
| SubagentStart       | Sub-agent starts                          |
| SubagentStop        | Sub-agent stops                           |
| PreCompact          | Before context compaction                 |
| PermissionRequest   | Permission is being requested             |

================================================================================
HOOK INPUT TYPES (What data each hook receives)
================================================================================

1. PreToolUseHookInput:
   {
     hook_event_name: 'PreToolUse',
     tool_name: string,          // e.g., 'Read', 'Bash', 'Edit', 'Glob'
     tool_input: unknown,        // Tool-specific input object
     tool_use_id: string,        // Unique ID for this tool call
     session_id: string,
     transcript_path: string,
     cwd: string,
     permission_mode?: string
   }

2. PostToolUseHookInput:
   {
     hook_event_name: 'PostToolUse',
     tool_name: string,
     tool_input: unknown,
     tool_response: unknown,     // The result from the tool
     tool_use_id: string,
     session_id: string,
     transcript_path: string,
     cwd: string
   }

3. PostToolUseFailureHookInput:
   {
     hook_event_name: 'PostToolUseFailure',
     tool_name: string,
     tool_input: unknown,
     tool_use_id: string,
     error: string,              // Error message
     is_interrupt?: boolean,     // Was it an interruption?
     session_id: string,
     transcript_path: string,
     cwd: string
   }

4. NotificationHookInput:
   {
     hook_event_name: 'Notification',
     message: string,
     title?: string,
     notification_type: string,
     session_id: string,
     transcript_path: string,
     cwd: string
   }

5. UserPromptSubmitHookInput:
   {
     hook_event_name: 'UserPromptSubmit',
     prompt: string,             // The user's prompt
     session_id: string,
     transcript_path: string,
     cwd: string
   }

6. SessionStartHookInput:
   {
     hook_event_name: 'SessionStart',
     source: 'startup' | 'resume' | 'clear' | 'compact',
     session_id: string,
     transcript_path: string,
     cwd: string
   }

7. SessionEndHookInput:
   {
     hook_event_name: 'SessionEnd',
     reason: string,             // Why the session ended
     session_id: string,
     transcript_path: string,
     cwd: string
   }

================================================================================
HOOK RETURN VALUES (How to control behavior)
================================================================================

Hooks can return an object with these optional properties:

{
  continue?: boolean,           // Whether to continue execution
  suppressOutput?: boolean,     // Hide output from user
  stopReason?: string,          // Stop with this reason
  decision?: 'approve' | 'block', // Permission decision
  systemMessage?: string,       // Inject message to Claude
  reason?: string,              // Reason for decision

  // Hook-specific outputs:
  hookSpecificOutput?: {
    hookEventName: 'PreToolUse',
    permissionDecision?: 'allow' | 'deny' | 'ask',
    permissionDecisionReason?: string,
    updatedInput?: Record<string, unknown>  // Modify tool input
  } | {
    hookEventName: 'PostToolUse',
    additionalContext?: string,
    updatedMCPToolOutput?: unknown
  } | ...
}

IMPLEMENTATION STEPS TO ADD ENHANCED NOTIFICATIONS
================================================================================

STEP 1: Add Missing Hooks to claude-handler.ts
----------------------------------------------

In the sdkOptions.hooks object, add these additional hooks:

```typescript
hooks: {
  // Existing PreToolUse hook...
  PreToolUse: [{
    matcher: '.*',
    hooks: [async (input: any, toolUseId: string, context: any) => {
      const toolName = input?.tool_name || 'unknown'
      const toolInput = input?.tool_input || {}

      // Emit detailed activity based on tool type
      let activity = { action: 'using', target: toolName, details: '' }

      if (toolName === 'Read') {
        activity = { action: 'reading', target: toolInput.file_path, details: '' }
      } else if (toolName === 'Write') {
        activity = { action: 'writing', target: toolInput.file_path, details: '' }
      } else if (toolName === 'Edit') {
        activity = { action: 'editing', target: toolInput.file_path, details: '' }
      } else if (toolName === 'Bash') {
        activity = { action: 'running', target: 'command', details: toolInput.command }
      } else if (toolName === 'Glob') {
        activity = { action: 'searching', target: 'files', details: toolInput.pattern }
      } else if (toolName === 'Grep') {
        activity = { action: 'searching', target: 'content', details: toolInput.pattern }
      } else if (toolName === 'WebSearch') {
        activity = { action: 'searching', target: 'web', details: toolInput.query }
      } else if (toolName === 'WebFetch') {
        activity = { action: 'fetching', target: 'url', details: toolInput.url }
      }

      this.emit('activity', activity)
      this.emit('tool_use', { name: toolName, input: toolInput })

      // Permission handling...
      return {}
    }]
  }],

  // Add PostToolUseFailure hook
  PostToolUseFailure: [{
    matcher: '.*',
    hooks: [async (input: any) => {
      const toolName = input?.tool_name || 'unknown'
      const error = input?.error || 'Unknown error'

      console.error(`Tool failed: ${toolName} - ${error}`)
      this.emit('tool_error', { name: toolName, error })

      return {}
    }]
  }],

  // Add SessionStart hook
  SessionStart: [{
    matcher: '.*',
    hooks: [async (input: any) => {
      console.log(`Session started: ${input.source}`)
      this.emit('session_start', { source: input.source })
      return {}
    }]
  }],

  // Add SessionEnd hook
  SessionEnd: [{
    matcher: '.*',
    hooks: [async (input: any) => {
      console.log(`Session ended: ${input.reason}`)
      this.emit('session_end', { reason: input.reason })
      return {}
    }]
  }],

  // Add Notification hook
  Notification: [{
    matcher: '.*',
    hooks: [async (input: any) => {
      console.log(`Notification: ${input.title} - ${input.message}`)
      this.emit('notification', {
        title: input.title,
        message: input.message,
        type: input.notification_type
      })
      return {}
    }]
  }],

  // Add UserPromptSubmit hook for logging
  UserPromptSubmit: [{
    matcher: '.*',
    hooks: [async (input: any) => {
      console.log(`Prompt submitted: ${input.prompt?.substring(0, 50)}...`)
      this.emit('prompt_submitted', { prompt: input.prompt })
      return {}
    }]
  }]
}
```


STEP 2: Update index.ts to Listen for New Events and Send to Frontend
----------------------------------------------------------------------

```typescript
// Add more event listeners after the existing claude.on('tool_use', ...)

claude.on('activity', async (activity) => {
  console.log(`Activity: ${activity.action} ${activity.target}`)
  await sendToFrontend({
    type: 'claude_activity',
    action: activity.action,
    target: activity.target,
    details: activity.details
  })
})

claude.on('tool_error', async (error) => {
  console.error(`Tool error: ${error.name} - ${error.error}`)
  await sendToFrontend({
    type: 'claude_error',
    tool: error.name,
    error: error.error
  })
})

claude.on('session_start', async (data) => {
  console.log(`Session started: ${data.source}`)
  await sendToFrontend({ type: 'session_start', source: data.source })
})

claude.on('session_end', async (data) => {
  console.log(`Session ended: ${data.reason}`)
  await sendToFrontend({ type: 'session_end', reason: data.reason })
})

claude.on('notification', async (notification) => {
  await sendToFrontend({
    type: 'claude_notification',
    title: notification.title,
    message: notification.message
  })
})

claude.on('prompt_submitted', async (data) => {
  console.log(`Processing: ${data.prompt?.substring(0, 30)}...`)
  await sendToFrontend({
    type: 'processing_prompt',
    preview: data.prompt?.substring(0, 100)
  })
})
```


STEP 3: Handle Tool Progress Messages (for long-running tools)
--------------------------------------------------------------

In the message loop in claude-handler.ts, add handling for tool_progress:

```typescript
for await (const message of query({ prompt, options: sdkOptions, ... })) {
  // Existing message handling...

  // Add tool progress handling
  if ((message as any).type === 'tool_progress') {
    const progress = message as any
    this.emit('tool_progress', {
      tool_name: progress.tool_name,
      tool_use_id: progress.tool_use_id,
      elapsed_seconds: progress.elapsed_time_seconds
    })
  }
}
```


STEP 4: Enable Partial/Streaming Messages (optional)
----------------------------------------------------

To get streaming text updates as Claude generates responses, add to SDK options:

```typescript
const sdkOptions: ClaudeAgentOptions = {
  // ... existing options ...
  includePartialMessages: true,  // Enable streaming events
}
```

Then handle SDKPartialAssistantMessage in the message loop to emit
partial text updates.


================================================================================
STREAM MESSAGE TYPES FOR REAL-TIME UPDATES
================================================================================

The SDK emits these message types during streaming:

| Message Type                  | Description                              |
|-------------------------------|------------------------------------------|
| SDKToolProgressMessage        | Progress updates for long-running tools  |
| SDKPartialAssistantMessage    | Streaming text as it's generated         |
| SDKAssistantMessage           | Complete assistant message               |
| SDKUserMessage                | User input                               |
| SDKResultMessage              | Final result with usage stats            |
| SDKSystemMessage              | Init, status, compact boundary           |
| SDKHookResponseMessage        | Response from hooks                      |
| SDKAuthStatusMessage          | Authentication status updates            |

SDKToolProgressMessage structure:
{
  type: 'tool_progress',
  tool_use_id: string,
  tool_name: string,
  parent_tool_use_id: string | null,
  elapsed_time_seconds: number,    // How long tool has been running
  uuid: UUID,
  session_id: string
}


================================================================================
FRONTEND DATA CHANNEL PROTOCOL
================================================================================

The current implementation sends data to the frontend via LiveKit data channel.
Message types being sent:

Current:
- { type: 'system', text: 'Working on: ...' }
- { type: 'assistant_response', text: '...' }

Recommended additions:
- { type: 'claude_activity', action: string, target: string, details: string }
- { type: 'claude_error', tool: string, error: string }
- { type: 'tool_progress', tool: string, elapsed: number }
- { type: 'session_start', source: string }
- { type: 'session_end', reason: string }
- { type: 'claude_notification', title: string, message: string }
- { type: 'processing_prompt', preview: string }

EXAMPLE: COMPLETE ENHANCED HOOKS CONFIGURATION
================================================================================

```typescript
const sdkOptions: ClaudeAgentOptions = {
  allowedTools: this.options.allowedTools,
  cwd: this.options.workingDirectory,
  permissionMode: this.options.permissionMode,
  includePartialMessages: true,  // For streaming updates
  ...(this.sessionId && { resume: this.sessionId }),

  hooks: {
    PreToolUse: [{
      matcher: '.*',
      timeout: 30,  // 30 second timeout for hook
      hooks: [async (input, toolUseId, context) => {
        const toolName = input?.tool_name || 'unknown'
        const toolInput = input?.tool_input || {}

        // Emit detailed activity
        this.emitToolActivity(toolName, toolInput)

        // Handle permissions if needed
        if (this.requiresPermission(toolName)) {
          const approved = await this.requestPermission(toolName, toolInput, toolUseId)
          if (!approved) {
            return { decision: 'block', reason: 'User denied permission' }
          }
        }

        return {}
      }]
    }],

    PostToolUse: [{
      matcher: '.*',
      hooks: [async (input) => {
        this.emit('tool_result', {
          name: input?.tool_name,
          response: input?.tool_response
        })
        return {}
      }]
    }],

    PostToolUseFailure: [{
      matcher: '.*',
      hooks: [async (input) => {
        this.emit('tool_error', {
          name: input?.tool_name,
          error: input?.error,
          isInterrupt: input?.is_interrupt
        })
        return {}
      }]
    }],

    SessionStart: [{
      matcher: '.*',
      hooks: [async (input) => {
        this.emit('session_start', { source: input.source })
        return {}
      }]
    }],

    SessionEnd: [{
      matcher: '.*',
      hooks: [async (input) => {
        this.emit('session_end', { reason: input.reason })
        return {}
      }]
    }],

    Notification: [{
      matcher: '.*',
      hooks: [async (input) => {
        this.emit('notification', {
          title: input.title,
          message: input.message,
          type: input.notification_type
        })
        return {}
      }]
    }],

    UserPromptSubmit: [{
      matcher: '.*',
      hooks: [async (input) => {
        this.emit('prompt_submitted', { prompt: input.prompt })
        return {}
      }]
    }],

    PermissionRequest: [{
      matcher: '.*',
      hooks: [async (input) => {
        // Handle permission UI
        this.emit('permission_needed', {
          tool: input.tool_name,
          input: input.tool_input,
          suggestions: input.permission_suggestions
        })
        return {}
      }]
    }]
  }
}
```
